An image editor designed **for** AI.

## Why?

Image editors have barely changed in the last 30 years.

They keep adding more tools, more panels, more buttons...

Then AI arrived.

Most applications simply added an "AI" button.

**NABU asks a different question.**

> *What if image editing was designed today?*

No endless toolbars.

No hidden menus.

No learning curve measured in months.

Just tell the editor what you want.

---

## Philosophy

NABU is built around **intent**, not tools.

Instead of asking:

- Which brush?
- Which filter?
- Which menu?

NABU asks:

> **What do you want to achieve?**

Examples:

- Remove this object
- Change the sky
- Restore this old photo
- Make it cinematic
- Improve sharpness
- Prepare it for LinkedIn

The software decides **how**.

You decide **what**.

## A different interface

Traditional editors expose hundreds of tools.

NABU exposes only what you need.

Most controls appear **only when they make sense**.

The image always comes first.

---

## Local-first

Your images stay on your computer.

Whenever possible, AI models run locally.

No mandatory accounts.

No cloud dependency.

No subscriptions required.
